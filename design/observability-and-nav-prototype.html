Playbooks and Planning promoted; Search demoted (shortcut shown); Tools renamed MCPs; Observability added.

Search keeps its ⌘K shortcut, so demoting it costs a click only for pointer users who never learned the shortcut. The bar has no responsive collapse today — every control is shrink-0 and labels merely hide below sm, so adding two labelled items narrows the usable width on small screens. That is the main risk in this change.

The two panels are already nearly identical in code — same border, radius, surface, padding and shadow-xl. The perceived gap is the trigger, the item styling and the missing behaviour, not the panel. Both menus currently use shadow-xl; only notification-popover.tsx uses the app's purpose-built has-shadow-overlay. This mockup applies it to both.
